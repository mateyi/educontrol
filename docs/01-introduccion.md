# 01. Introducción

## 1. Resumen Ejecutivo
**EduControl** es una plataforma web Full Stack de nivel corporativo desarrollada como proyecto final integrador para la materia **Laboratorio de Software** de la educación secundaria técnica de Argentina.

El sistema digitaliza, centraliza y optimiza todos los flujos operativos, académicos y de comunicación de una institución escolar secundaria, tales como:
- Control digital de asistencia diaria y por horas cátedra.
- Libro de temas y calificaciones trimestrales con escala de 1 a 10 y umbral mínimo de aprobación en 7.0 puntos.
- Generación de boletines oficiales de calificaciones.
- Detección de conflictos en la distribución de horarios y aulas.
- Gestión de tareas y entregas digitales de trabajos prácticos.
- Cartelera institucional segmentada.
- Control de acceso basado en roles estrictos (RBAC) con 6 perfiles diferenciados: **Administrador**, **Directivo**, **Preceptor**, **Profesor**, **Alumno** y **Tutor**.

## 2. Tecnologías Empleadas
- **Frontend:** React 18, TypeScript, Vite, Tailwind CSS, Lucide Icons, Recharts, React Router.
- **Backend:** Node.js, Express, TypeScript, REST API, JSON Web Tokens (JWT), Bcrypt, Zod.
- **Base de Datos & ORM:** PostgreSQL / SQLite, Prisma ORM.
- **Testing:** Vitest, Supertest, Playwright.
